# Gennaio

Primer prototipo de una nueva experiencia web para Gennaio, estudio de interiorismo y mobiliario a medida.

## Desarrollo local

Requiere Node.js 20.9 o superior.

```bash
npm install
npm run dev
```

Abrir [http://localhost:3000](http://localhost:3000).

## Verificación

```bash
npm run lint
npm run build
```

Las decisiones iniciales de diseño e interacción están documentadas en [`docs/draft.md`](docs/draft.md).
